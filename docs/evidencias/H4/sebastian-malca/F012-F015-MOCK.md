## Arquitectura

`ProductCommerce` es el único **contenedor** que ejecuta
`useProductVariants`, `useProductPrice` y `useProductAvailability`. Las regiones
de precio, variantes y disponibilidad son **presentacionales** y no llaman
servicios. `RelatedProductsRegion` ejecuta `useRelatedProducts` de forma
independiente para no bloquear la ficha.

Flujo: variante seleccionada → SKU único → consultas de precio y disponibilidad
por SKU → CTA F-016 habilitado sólo con precio listo y disponibilidad conocida.

## Reglas de negocio cubiertas (Frontend)

### F-012 — precio, oferta y descuento
- `RC-F-012-01`: sin SKU aplicable no se consulta ni se hereda precio ajeno;
  producto con variantes muestra «Selecciona una opción para ver el precio».
- `RC-F-012-02`: sin oferta vigente no se inventa 0 % de descuento.
- `RC-F-012-03`: una oferta caducada retira badge, precio de referencia y
  descuento a la vez (`normalizePrice`).
- `RC-F-012-04`: un error de precio se muestra dentro de su región con
  reintento; la descripción y las especificaciones siguen visibles.
- Importes en `es-PE` con `Intl.NumberFormat` (NBSP: `S/ 254.90`).

### F-013 — atributos y variantes
- `RC-F-013-01`: al cambiar un atributo se poda la selección incompatible y se
  elimina el SKU anterior; nunca se conserva una combinación inválida.
- `RC-F-013-02`: una variante agotada sigue siendo seleccionable; el estado de
  stock lo comunica F-014, no el selector.
- `RC-F-013-03`: producto simple (`hasVariants: false`) no renderiza selector.
- `RC-F-013-04`: al resolver un SKU nuevo se consultan precio y disponibilidad
  de ese SKU y desaparecen los del anterior.
- Accesibilidad: grupos con `role="group"` + `aria-labelledby`, `aria-pressed`,
  valores incompatibles deshabilitados con explicación y resumen con
  `aria-live="polite"`.

### F-014 — disponibilidad
- `RC-F-014-01`: un 503/502/504 de inventario se muestra como error con
  reintento y **nunca** como «Agotado».
- `RC-F-014-02`: sin SKU no se ejecuta la consulta ni se muestra un estado
  ficticio.
- `RC-F-014-03`: la respuesta se indexa por `slug:sku:intento`, así que una
  respuesta del SKU anterior se descarta.
- `RC-F-014-04`: sólo se renderiza texto e icono; no se muestran cantidades ni
  ubicaciones (el adaptador rechaza esos campos si aparecen).
- Estados admitidos: `AVAILABLE`, `STOCK_LOW`, `OUT_OF_STOCK`. `INDETERMINADO`
  queda pendiente de G-G6-COMPAT y hoy invalida la respuesta (502 tipado).

### F-015 — productos relacionados
- `RC-F-015-01`: arreglo vacío omite título y sección completos.
- `RC-F-015-02`: un fallo técnico degrada a `[]` y no afecta la ficha.
- `RC-F-015-03`: `price: null` no muestra importe; nunca se presenta `0`.
- `RC-F-015-04`: cada tarjeta navega a `/productos/{slug}`; no requiere SKU.
- Se respeta el orden del BFF (`presentationOrder`); máximo 8 tarjetas.

### Integración F-016
El CTA se habilita sólo con precio listo y disponibilidad `AVAILABLE`/`STOCK_LOW`;
`LOADING` y `ERROR` no muestran un CTA engañoso y `waiting_for_sku` se traduce a
`UNSELECTED`. El payload sigue siendo `productId`; la integración de carrito por
SKU queda fuera de este slice.
