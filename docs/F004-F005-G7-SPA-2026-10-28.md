# Entrada G1 a recuperación G7 — F-004/F-005

Responsable: Jim Segovia · Revisor: Andrés Morales · [FE #23](https://github.com/Taller-SW-Web/G1-Marketplace-Frontend/issues/23) y [FE #25](https://github.com/Taller-SW-Web/G1-Marketplace-Frontend/issues/25).

La decisión del PO del 26/10/2026 asigna los formularios de recuperación y restablecimiento a la SPA G7. [SPECS PR #14](https://github.com/Taller-SW-Web/G1-Marketplace-SPECS/pull/14) alinea el contrato G1. Esta rama cambia únicamente la entrada web G1; no modifica la SPA G7 ni el BFF.

## Comportamiento

- `/login` muestra «¿Olvidaste tu contraseña?» con enlace directo a la URL fija `NEXT_PUBLIC_G7_RECOVERY_URL`.
- `/recuperar-contrasena` redirige temporalmente a esa misma URL para enlaces internos o marcadores anteriores. Si falta una URL válida, muestra una salida accesible sin formulario local.
- `/restablecer-contrasena` ya no procesa tokens en G1. Muestra el paso a Seguridad o retorno a login, y borra query, fragmento y estado de historial del navegador cuando se monta. Nunca reenvía un token recibido a G7.
- Las APIs BFF/web de G1 permanecen disponibles para integración y pruebas; el cambio de interfaz no implica cierre de F-004/F-005.

## Configuración y límites

Definir `NEXT_PUBLIC_G7_RECOVERY_URL` antes del build de Next con la URL absoluta de la SPA G7, ruta exacta `/recuperar-contrasena`, sin usuario, contraseña, query ni fragmento. En producción se acepta sólo HTTPS; HTTP loopback es exclusivo de desarrollo/pruebas. La URL pública no contiene secretos. Por ser `NEXT_PUBLIC_`, Next la incorpora al build: un cambio requiere un nuevo build y despliegue.

El login no agrega correo, token, canal ni callback a la URL. G7 debe configurar por su lado el retorno fijo permitido a `/login` del origen G1. Hasta que G7 lo publique y se pruebe en navegador, el recorrido completo sigue pendiente. No usar una respuesta HTTP aislada como aprobación de la UI.

## Verificación local del 28/10

- `npm run typecheck`, `npm run lint -- --quiet`, `npm run build` y `npm run test:components` pasaron.
- Con URL G7 fija en servidor Next local, `GET /recuperar-contrasena` dio 307 hacia la ruta G7 y `GET /login` dio 200 con enlace directo a esa ruta. No se usaron cuentas ni correos.
- Las pruebas nuevas rechazan URL con query, fragmento, credenciales, ruta incorrecta o HTTP externo; comprueban enlace y limpieza de una URL heredada.

Pendiente para cierre: configurar la variable en Vercel, certificar SHA/ID del deployment, comprobar navegación desktop/mobile y retorno G7→G1 con un enlace nuevo, casos negativos, revisión independiente y criterios de las issues vinculadas.
